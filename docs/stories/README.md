## Workflow

1. **Story Created** - Story documented and added to backlog
2. **Story Ready** - Acceptance criteria defined, dependencies identified
3. **Story In Progress** - Development started
4. **Story Review** - Code review in progress
5. **Story Done** - All DoD criteria met
6. **Story Accepted** - Product Owner approval
