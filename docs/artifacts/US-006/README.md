# Images Directory

This directory contains all visual assets for the Personal Finance Manager project.

## Directory Structure

```
images/
├── ui-screenshots/         # UI component test screenshots (IGNORED by git)
│   └── YYYYMMDD_HHMMSS/   # Timestamped test runs
├── e2e-screenshots/       # End-to-end test screenshots (IGNORED by git)
│   └── run_YYYYMMDD_HHMMSS/  # Timestamped test runs
├── regression-tests/      # Visual regression testing (IGNORED by git)
│   ├── baseline/          # Known good screenshots
│   ├── current/           # Latest test screenshots
│   └── diff/              # Visual diff images
├── docs/                  # Documentation images (COMMITTED to git)
│   └── (screenshots for documentation)
└── architecture/          # Architecture diagrams (COMMITTED to git)
    └── (system diagrams, flow charts, etc.)
```

## Screenshot Directories (Auto-Generated)

The following directories are automatically created and populated by automated tests:

### `ui-screenshots/`
- **Purpose**: Screenshots from UI component testing
- **Generated by**: frontend-dev agent with xvfb
- **Format**: Timestamped directories with descriptive filenames
- **Example**: `images/ui-screenshots/20251026_100500/01-main-window.png`
- **Git**: Ignored (not committed)

### `e2e-screenshots/`
- **Purpose**: Screenshots from end-to-end workflow tests
- **Generated by**: tech-lead agent with xvfb + MCP
- **Format**: Test run directories with test scenario screenshots
- **Example**: `images/e2e-screenshots/run_20251026_110000/test1-01-initial.png`
- **Git**: Ignored (not committed)

### `regression-tests/`
- **Purpose**: Visual regression testing comparisons
- **Generated by**: Automated regression test scripts
- **Subdirectories**:
  - `baseline/`: Known good screenshots to compare against
  - `current/`: Latest test run screenshots
  - `diff/`: Visual difference images (ImageMagick compare)
- **Git**: Ignored (not committed)

## Documentation Images (Manual)

### `docs/`
- **Purpose**: Screenshots and images for documentation
- **Created by**: Developers manually
- **Examples**: User guide screenshots, feature demonstrations
- **Git**: Committed to repository

### `architecture/`
- **Purpose**: System architecture diagrams
- **Created by**: Tech lead, developers

- **Git**: Committed to repository

## Usage with Xvfb

Both the frontend-dev and tech-lead agents are configured to use xvfb for automated UI testing.

### Taking Screenshots

**Manual screenshot during development:**
```bash
export DISPLAY=:99
mkdir -p images/ui-screenshots
DISPLAY=:99 scrot images/ui-screenshots/screenshot.png
```

**Automated testing with pytest:**
```python
# Screenshots are automatically saved to timestamped directories
pytest tests/e2e/test_transaction_workflow.py
# Results in: images/e2e-screenshots/run_20251026_100500/
```

### Viewing Screenshots

```bash
# List all screenshots from latest test run
ls -lh images/e2e-screenshots/$(ls -t images/e2e-screenshots/ | head -1)/

# Open screenshots with default viewer
xdg-open images/e2e-screenshots/run_20251026_100500/01-initial.png

# Or use your preferred image viewer
eog images/e2e-screenshots/run_20251026_100500/*.png
```

## Cleanup

### Automatic Cleanup (Recommended)
```bash
# Keep only last 10 test runs
cd images/e2e-screenshots
ls -t | tail -n +11 | xargs rm -rf

# Delete runs older than 7 days
find images/e2e-screenshots -type d -mtime +7 -exec rm -rf {} +
```

### Manual Cleanup
```bash
# Remove all test screenshots (careful!)
rm -rf images/ui-screenshots/*
rm -rf images/e2e-screenshots/*
rm -rf images/regression-tests/current/*
rm -rf images/regression-tests/diff/*
```

**Note**: Never delete `regression-tests/baseline/` unless you're updating baseline images.

## Best Practices

1. **Don't commit test screenshots** - They are auto-generated and can be large
2. **Do commit documentation images** - They are valuable for understanding the project
3. **Name screenshots descriptively** - Use format: `NN-action-description.png`
4. **Organize by test run** - Use timestamped directories
5. **Clean up old runs** - Don't let screenshot directories grow unbounded
6. **Document baseline updates** - Note when and why regression baselines change
